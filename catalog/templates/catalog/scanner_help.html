Команды сканера

Откройте PowerShell или командную строку, перейдите в папку, где установлен сканер (команда cd и путь к этой папке). Подставьте свои диск и папки вместо примеров. Ждите окончания — окно не закрывайте до сообщения об успехе или ошибке.

Основное — сканирование

Все пути из файла настроек scanner.yaml рядом со сканером (если он у вас есть):

py -m scanner.cli scan

Одна выбранная папка (пример — документы пользователя):

py -m scanner.cli scan --path "C:\Users\ИмяПользователя\Documents"

Если команда metastore-scanner уже доступна в системе:

metastore-scanner scan --path "D:\МояПапка"

Только нужные расширения (PDF, Word, Excel и т.д.)

Слово --ext повторяют для каждого типа. Можно писать pdf или .pdf.

py -m scanner.cli scan --ext pdf --ext docx --path "C:\Users\ИмяПользователя\Documents"

Если нужны только файлы, уже учтённые раньше (например только PDF из базы на компьютере)

py -m scanner.cli scan --find "*.pdf" --path "C:\Users\ИмяПользователя\Downloads"

То же через расширение:

py -m scanner.cli scan --ext pdf --path "C:\Users\ИмяПользователя\Downloads"

Если нужно найти на диске все файлы по маске (не только старые записи)

py -m scanner.cli scan --ext pdf --find-discover-all --path "C:\Users\ИмяПользователя\Downloads"

Прочее

Очистить локальный кэш сканера на этом компьютере:

py -m scanner.cli reset-cache

Отправить на сервер то, что накопилось в очереди:

py -m scanner.cli sync

Проверить, отвечает ли сервер:

py -m scanner.cli status

Посмотреть, как компьютер видит себя для регистрации:

py -m scanner.cli device-info

Полный список ключей для команды scan:

py -m scanner.cli scan --help

После удачной отправки на сервер

Откройте в верхнем меню пункт Разбор скана: отметьте файлы, выберите проект и теги, нажмите Сохранить выбранные.
